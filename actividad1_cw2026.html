Actividad 1 de HTML: Análisis de codigo

Codigo en C:

 
     
    #include <stdio.h>

    int main (){
        int edad;
        printf("Ingresa tu edad");
        scanf("%i", &edad);

        if (edad >= 18)
            printf("Eres mayor de edad\n");
        else
            printf("Eres menor de edad\n");

        return 0;
    }

Explicación:

La linea

#include <stdio.h>

funciona para incluir la biblioteca estandar de entradas y salidas.

La funcion de 

    
    int main (){
        ...
    }

Es la principar de nuestra función, donde se ejecuta todo el programa

Nos devuelve un valor void y devuelve un valor entero

Declaramos una variable de tipo entero

int edad;

Solicitamos al usuario ingresar su edad

printf("Ingresa tu edad");

Guardamos la edad en la variable creada

scanf("%i", &edad);

El condicional

if (edad >= 18)

nos comprueba si la edad es mayor a 18 años

Si es mayor a 18 ejecuta: 

printf("Eres mayor de edad\n");

Sino, ejecuta: 

printf("Eres menor de edad\n");

Finalmente ejecuta la siguente linea para indicar que el programa termino con exito

return 0;
