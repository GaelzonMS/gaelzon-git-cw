Etiquetas HTML - mi referencia
Etiqueta ¿Para qué sirve? Ejemplo mínimo
<main> Es el espacio donde se coloca el contenido principal 

                        
<main>
    <section>Items de la seccion</section>
    <section>Items de la seccion</section>
</main>
<ul> Crea una lista desordenada 

<h2>Lista desordenada</h2>
<ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
    <li>Elemento 3</li>
</ul>
<li> Es un item de una lista 

<h2>Lista ordenada</h2>
<ol>
    <li>Elemento generico de lista</li>
</ol>
<code> Sirve para poner un codigo 

<code>
    printf("hola mundo");
</code>
<section> Sirve para crear una sección temática 

                        
<h2>Ejemplo de seccion</h2>
<section>
    <div>Contenedor 1</div>
    <div>Contenedor 2</div>
</section>
